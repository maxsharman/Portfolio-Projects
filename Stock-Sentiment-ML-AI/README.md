# Stock Market Twitter Sentiment Analysis

This project explores the relationship between social media sentiment and stock market performance. 
Using static stock market data combined with a dataset of tweets, the goal is to determine whether 
Twitter sentiment can help predict stock price movements.

To extract sentiment from tweets, the project uses the LLM 'BERT'. 
These sentiment scores are then fed into multiple machine learning and deep learning models to evaluate 
how well they can predict unseen stock data.

**Tools & Technologies**

* Python

* Pandas, NumPy

* Scikit-learn

* TensorFlow / Keras

* BERT (for sentiment extraction)

* Matplotlib / Seaborn
